# 键鼠助手 Mac

这是基于 MIT 开源项目 Infinite Autoclicker 改造的 macOS 键鼠自动化工具项目。

## 功能

- 全局录制鼠标移动、点击、滚轮和键盘操作；
- 按原始节奏回放，可选择 0.25×–4× 速度；
- 回放次数设为 0 时无限循环，直到再次按播放键或按 F12 紧急停止；
- 默认提供 2 像素点击随机偏移，也可调节位置、时间和移动路径偏移；
- 自动点击支持固定位置、间隔、左右键、双击及无限次数；
- 工作流保存为本地 JSON，可复制给另一台 Mac 导入；
- 全程本地运行，不包含遥测和网络功能；
- 支持 macOS 12 及以上版本。

## macOS 权限

第一次启动后，在“系统设置 → 隐私与安全性”中允许：

1. **辅助功能**：用于模拟鼠标和键盘；
2. **输入监控**：用于录制键鼠操作；
3. **屏幕录制**：只有使用颜色识别功能时才需要。

授权后如果仍不能录制或回放，请完全退出应用后重新打开。

## 快捷键

- F6：开始/停止自动点击；
- F7：开始/停止录制；
- F8：开始/停止回放；
- F9：获取鼠标位置；
- F12：立即停止所有自动操作。

## 在 Mac 上生成应用

需要 macOS、Xcode Command Line Tools、Rust 和 Bun（或 Node.js 18+）：

```bash
bun install
bun run tauri build
```

生成的 `.app` 和 `.dmg` 位于 `src-tauri/target/release/bundle/`。

未购买 Apple Developer 证书时，首次启动请右键应用选择“打开”。正式向他人分发时，
建议使用 Developer ID 完成签名和 Apple 公证，否则每台 Mac 都可能显示安全提醒。

## 安全提醒

不要录制密码、验证码、支付信息或密钥。导入别人提供的工作流前，应检查其步骤并先在
无风险环境中测试。自动化也可能违反某些游戏或网站的使用规则。
